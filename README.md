# Configurable Profit Calculator

A CLI profit calculator for OSRS/RuneScape money makers.

## Personal Usage

I wanted to build something that allows me to quickly compare the profit differences between necklaces in f2p osrs so that I can craft the most profitable ones at any given time. It won't make me rich, but hopefully, it'll be something I'll want to use regularly.

## Features

- Calculate profit per item with GE tax adjusted automatically
- Manual input mode for any custom methods
- Auto-fetch live prices from OSRS Wiki API
- Auto-calculate all craftable necklaces
- Save results to SQLite database

## Tech Stack

- **Language:** Go
- **Database:** SQLite
